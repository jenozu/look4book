# 50 — Backtests / Validation

For Look4Book, "backtests" means validating pricing and recommendation logic against known examples.

Useful records include:

- ISBN
- Physical purchase price
- Prices returned by the app
- Manual marketplace comparison
- App recommendation
- Actual decision
- Actual sale price later, if bought
- Notes on condition/edition mismatch

Use this folder to determine whether the pricing engine is genuinely useful rather than merely plausible.
