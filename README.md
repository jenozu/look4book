# Look4Book

Look4Book is a lean personal book-resale sourcing tool.

The MVP goal is simple:

> **Scan an ISBN → identify the book → enter the thrift price → estimate resale value → BUY / MAYBE / PASS.**

## Core MVP

- Mobile-first ISBN barcode scanning
- Manual ISBN fallback
- Book metadata lookup
- Purchase-price entry in CAD
- Marketplace price lookup, starting with one reliable source
- Approximate fees and shipping
- Estimated profit and ROI
- BUY / MAYBE / PASS recommendation
- Confidence indicator
- Installable PWA polish

## Working rule

Keep the project personal and lean. Do not add accounts, subscriptions, inventory management, automated marketplace listing, or advanced AI features until the scanner-to-decision MVP works reliably.
